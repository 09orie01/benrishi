# benrishi

弁理士向けの商標調査ツールの準備用リポジトリです。

## jpo-check（試し用の定期実行）

特許庁の「類似商品・役務審査基準」の索引ページから最新版を見つけ、Excel をダウンロードして、その構造を表示します。

- 手動で実行: 「Actions」タブ → 「jpo-check」 → 「Run workflow」
- 定期実行は止めています。2026-10-23 の試験で、特許庁のサイトから HTTP 403 で拒否されたためです。
- 結果: 実行画面のログと、「Artifacts」の `jpo-check-output`（Excel と `summary.json`）

終了コードが 1 のときは、特許庁のページの形が変わったか、自動アクセスが拒否された可能性があります。

## 公開用の一覧データ（docs/master.json）

事前確認の「公開した一覧データの読み込み」用のサンプルです。特許庁の解説ページにある例だけが入っています。実際の一覧ではありません。
